# Design System & UI Tokens

Scope: project-local

## Aesthetic Principles
- **Theme**: Dark glassmorphism (`rgba(15, 23, 42, 0.92)` with `backdrop-filter: blur(12px)`).
- **Icons**: Strictly premium Lucide-style inline SVGs. Zero emoji UI icons.
- **Typography**: Apple system font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI"`). Code highlight in monospace.
- **Color Tokens**:
  - Primary Accent: `#38bdf8` (Sky 400) / `#2563eb` (Blue 600)
  - Success / Active: `#4ade80` (Green 400)
  - Text Primary: `#f8fafc` (Slate 50)
  - Text Secondary: `#94a3b8` (Slate 400)
  - Border: `rgba(255, 255, 255, 0.12)`
